# משבץ תורנויות

הסקריפט משבץ בכל תאריך שני אנשים לשעה 06:20 ואדם שלישי לשעה 07:40. הוא מנסה:

1. לחלק את כלל התורנויות באופן שווה.
2. לחלק בנפרד גם את תורנויות 06:20 ו-07:40 באופן שווה.
3. לכבד אילוצים והעדפות.
4. לשבץ את שני האנשים של 06:20 מאותו חדר, ובמידת האפשר גם את האדם השלישי.

## שימוש

יש לערוך עותק של `example.json`, ואז להריץ:

```powershell
python scheduler.py example.json
```

לשמירת התוצאה בקובץ CSV שנפתח היטב ב-Excel:

```powershell
python scheduler.py example.json --output schedule.csv
```

אפשר להגדיר טווח רצוף בעזרת `start_date` ו-`end_date`, או להחליף אותם ברשימת תאריכים מפורשת:

```json
"dates": ["2026-08-09", "2026-08-11", "2026-08-14"]
```

## אילוצים והעדפות

לכל אדם אפשר להגדיר אילוצים לפי תאריך מדויק ו/או לפי יום קבוע בשבוע:

```json
"constraints": {
  "dates": {
    "2026-08-10": "unavailable",
    "2026-08-13": 2
  },
  "weekdays": {
    "ראשון": 3,
    "friday": 1
  }
}
```

- `unavailable` — האדם לא ישובץ בשום אופן.
- `0` — אין בעיה להשתבץ.
- `1` — עדיף שלא, אבל אפשר.
- `2` — העדפה חזקה שלא להשתבץ.
- `3` — העדפה חזקה מאוד; עדיין אפשר אם צריך כדי להשלים או לאזן את השיבוץ.

שמות הימים נתמכים בעברית (`ראשון` עד `שבת`) ובאנגלית. אם יש גם אילוץ לתאריך וגם אילוץ ליום בשבוע, האילוץ המחמיר מביניהם קובע.

אם ביום מסוים נשארו פחות משלושה אנשים זמינים, הסקריפט יעצור עם הודעה שמציינת את התאריך ואת הזמינים בו.
